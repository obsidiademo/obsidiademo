## EVORA changes

- Quicksand via Google Fonts in `sablon.twig` (overrides Nunito Sans picker default)
- Soft blush body `#fff7fa` + rose mist atmosphere
- `assets/evora-housewares.css` premium housewares layer
- Cart-detail hover blue `#2a73b7` → plum `#3e072c` (stay in pink family)
