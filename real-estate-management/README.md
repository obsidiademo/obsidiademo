# EmlakPro — Gayrimenkul Yönetim Platformu (HTML Demo)

Uçtan uca çalışan PropTech SaaS MVP demosu. Portföy, CRM, lead, randevu, yer gösterme, teklif/pazarlık, satış/kiralama, kira/depozito, komisyon/kasa ve ekip mesajlaşmasını tek platformda birleştirir.

## Çalıştırma

Tarayıcıda açın:

- Yönetim paneli: `real-estate-management/index.html`
- Son kullanıcı vitrini: `real-estate-management/public/index.html`

Yerel sunucu (önerilir):

```bash
cd real-estate-management
python3 -m http.server 8080
```

Sonra: http://localhost:8080

## Özellikler

- SPA tarzı yönetim paneli (modal / drawer / toast)
- localStorage CRUD
- Leaflet harita, Chart.js, FullCalendar, SortableJS kanban
- Quicksand font (zorunlu)
- Açık tema + opsiyonel dark mode
- Sahibinden tarzı vitrin + **10 seçilebilir tema**
- Admin panelden **Demoya Git** bağlantısı

## Senaryo

Panel içinde **Senaryo Demo** menüsünden uçtan uca satış senaryosunu çalıştırın.
