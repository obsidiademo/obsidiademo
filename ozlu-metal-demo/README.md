# Özlü Metal — Premium Kurumsal Web Sitesi Demo

Canlı demo: **https://www.obsidiademo.com.tr/ozlumetal/**

1983’ten beri faaliyet gösteren Özlü Metal Sanayi ve Ticaret Ltd. Şti. için hazırlanmış **Light Industrial Premium** HTML demosudur.

Mevcut site (`https://ozlumetal.com/`) kaynak alınarak ürünler, hizmetler, kurumsal metinler, iletişim bilgileri ve gerçek görseller korunmuş; arayüz sıfırdan tasarlanmıştır.

## Çalıştırma

Dosyayı tarayıcıda açın veya yerel sunucu kullanın:

```bash
cd ozlu-metal-demo
python3 -m http.server 8080
```

Ardından `http://localhost:8080` adresine gidin.

## Sayfalar

| Dosya | İçerik |
| --- | --- |
| `index.html` | Ana sayfa — hero, güven bandı, hakkımızda, ürün grupları, öne çıkan ürünler, çelik servis merkezi, hizmetler, galeri, çözüm bulucu, değerler, belgeler, CTA, iletişim |
| `products.html` | Tüm ürün kataloğu |
| `product-detail.html?id=...` | Ürün detayı |
| `corporate.html` | Hakkımızda, vizyon, misyon, değerler (sekmeler) |
| `manufacturing.html` | İmalat hatları ve makine teknik özellikleri |
| `documents.html` | Yayımlanan belgeler |
| `contact.html` | İletişim ve harita |

## Teknoloji

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts **Quicksand** (300–700)
- Lucide Icons
- Yerel WebP görseller (`assets/images/`)
